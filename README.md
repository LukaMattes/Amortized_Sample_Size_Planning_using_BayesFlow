# Amortized_Sample_Size_Planning_using_BayesFlow

This repository contains the code used for my work around amortized Sample Size Planning (SSP) using BayesFlow (Kühmichel et al., 2026; Radev et al., 2020) and benchmarking it against PyMC (Abril-Pla et al., 2023). Additionally, it contains the results obtained from performing SSP with this framework for four linear regression scenarios described in the top section of the file "ComparisonLinReg.py".

An accompanying tutorial is presented also, though this is still WIP.
